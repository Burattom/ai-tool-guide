### 英語コンテンツの注意

- 比較語は **"best X for Y" / "X vs Y" / "X pricing" / "X alternative"** が主戦場。競争が激しいため、独自の実測・価格表・確認日で差別化する。

- 成果確定まで 「承認 → 30〜90日 hold → 最低振込額到達」 で半年近くかかる前提で資金繰りを組む。

## Q4. 海外読者 × 国内ASP — 除外

**やらない。** 理由：

- A8.net 等の案件は日本の広告主・日本の読者を前提としており、英語記事から送客しても成果条件を満たせない
- 海外読者が日本のサービス（MiriCanvas等）に登録しても、ASPの計測対象外／報酬対象外になるケースが多い
- 日本語案件を英語で紹介しても、読者の支払い通貨・税率・契約条件の説明が破綻する

## Q6. 日本から受け取るためのインフラ

| 項目 | PartnerStack | impact.com |
|---|---|---|
| 最低出金 | $5 | $10 |
| 方法 | PayPal／Stripe／direct deposit（Airwallex） | 銀行／PayPal |
| 手数料 | PayPal 2%（最大$20）／Stripe $2.25+0.25%／日本のdirect deposit は$7＋0.60%〜 | PayPal 2%（最大$20）／銀行は3-5営業日 |
| 到達 | PayPal 6-10営業日／他2-5営業日 | 承認後1〜15日/任意 |
| 税フォーム | 非USは **W-8**（direct deposit の場合）。PayPal/Stripe なら PartnerStack 側では不要だが各社で必要 | 非USがUS brand と取引なら **W-8BEN / W-8BEN-E** |
| 注意 | 6か月支払えないと月次維持費が発生する場合あり（impact） | 通貨は登録後変更不可 |

### W-8BEN（日本在住の個人）

- 提出先は **支払者（各プラットフォーム）**。IRS に直接送るものではない（詐欺メール注意）。
- 未提出だと米国源泉徴収 **30%**。日米租税条約の適用で 0〜10%程度に軽減できるケースあり。
- 有効期限は署名した年から **3年後の年末**。更新忘れに注意。
- 日本側では別途、確定申告が必要。**「給与以外の所得が20万円超」は売上ではなく所得金額（収入−経費）で判定**。住民税は別途確認。
- 為替は「収益が確定した日」のレート（TTM 等）で円換算するのが原則。
