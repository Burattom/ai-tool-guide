### コンテンツ方針への示唆

- **「調べ物・比較」が主用途** → 「どれを選べばいいか」を解決する比較記事が検索意図に一致する。
- **誤情報への警戒が高い（85.1%が間違いを認識、信頼度は低下）** → 公式情報・確認日・出典を明示する「検証型」記事が差別化になる。AIに書かせただけの記事は逆に信頼を失う。
- **有料化はこれから（27.65% → 意向61.41%）** → 「無料枠で試す → 有料に進む判断」を支援する記事が、紹介料発生の真ん中に来る。
- **年代・職種で利用目的が違う** → 1つの「全体おすすめ」ではなく、ペルソナ別の入口を用意する。

## 2. ペルソナ定義（優先度つき）

### P1. 副業・フリーランス（最優先）

| 項目 | 内容 |
|---|---|
| 年齢・属性 | 20-40代、男性やや多め。会社員＋副業／独立したて |
| 今の悩み | 記事・SNS投稿・画像・資料作成に時間がかかる。ツールが多すぎて選べない |
| 検索語の例 | 「AIライティング おすすめ」「AI画像生成 無料」「資料作成 AI 比較」「Blog 自動生成 料金」 |
| 買うもの | ライティング／画像生成／資料作成ツールの有料プラン |
| 狙う案件 | Value AI Writer、ConoHa AI Canvas、MiriCanvas、Writesonic、Surfer、Frase、Gamma |
| 記事の約束 | 「無料枠でどこまでできるか」「月いくらで元が取れるか」を数字で示す |

### P2. AI初心者の社会人（最重要ボリューム）

| 項目 | 内容 |
|---|---|
| 年齢・属性 | 30-50代、管理職・一般社員。ChatGPT/Geminiは知っているが他有料ツールは未接触 |
| 今の悩み | 「使ったことはあるが仕事で使いこなせていない」「有料にする価値があるか分からない」 |
| 検索語の例 | 「生成AI 使い方 初心者」「ChatGPT 代替 無料」「AI プレゼン 作り方」「AI 料金 比較」 |
| 買うもの | 無料登録→有料プランへのアップグレード、学習講座 |
| 狙う案件 | MiriCanvas（新規無料登録）、DMM 生成AI CAMP（無料セミナー／入会）、Languise |
| 記事の約束 | 専門用語なしで「まずこれ1つ試せばいい」を提示。自動更新・解約も必ず書く |

### P3. 小規模事業者／マーケ・管理職（高単価）

| 項目 | 内容 |
|---|---|
| 年齢・属性 | 40-60代、役職層。チーム導入の意思決定者 |
| 今の悩み | 業務効率化、問い合わせ対応、採用・顧客獲得のコスト削減 |
| 検索語の例 | 「AI CRM 比較」「AI メールマーケ 料金」「AI 文字起こし 導入」「SEO ツール 比較」 |
| 買うもの | 年間契約・チームプラン（単価が高い） |
| 狙う案件 | HubSpot、Semrush、GetResponse、Surfer、n8n、Fireflies、Otter |
| 記事の約束 | 比較表・導入コスト・クッキー期間・契約条件を明示。CVRは低いが1件あたりが大きい |

### P4. コンテンツ制作者（SNS／動画）

| 項目 | 内容 |
|---|---|
| 年齢・属性 | 10-30代中心。YouTube／TikTok／Podcast／note 発信者 |
| 今の悩み | 動画編集、ナレーション、文字起こし、アバター制作の工数 |
| 検索語の例 | 「AI 音声生成 比較」「AI 動画編集 おすすめ」「文字起こし AI 無料」「AI アバター 料金」 |
| 買うもの | 音声・動画・文字起こしツール |
| 狙う案件 | ElevenLabs、Descript、Murf、Synthesia、OpusClip、Castmagic、Runway |
| 記事の約束 | 実際に作ったサンプルを見せる（体験の捏造は禁止。作れる範囲だけ正直に） |

### 補助：学生（10-20代）

利用率は最も高いが支払能力が低く、紹介料の直接源としては弱い。
**「無料枠の入口」として扱い、将来の有料化（P1/P2への移行）を見据えた認知獲得に留める。**

## 3. 最初に絞るべきペルソナ

**P1（副業・フリーランス）＋ P2（AI初心者社会人）** を主軸にする。

理由：
- 国内ASPのAI案件（無料登録系〜低額有料系）と相性が良い
- 検索ボリュームが大きく、比較記事で成果条件を満たしやすい
- 前プロジェクト（光回線比較）で効いた「失敗しないための確認ポイント」型の書き方がそのまま使える

P3・P4は、サイトにある程度の記事と検索流入が出てから（目安：GSCで月1,000PV以上）追加する。

## 5. 海外ペルソナ

### O1. 米国／英国のフリーランス・クリエイター（最優先）

| 項目 | 内容 |
|---|---|
| 属性 | 20-40代。自媒体・YouTube・Podcast・SNS運用 |
| 悩み | 動画／音声／画像生成の工数削減。ツールの月額をどう回収するか |
| 検索語 | "best AI voice generator", "ElevenLabs vs Murf", "AI video editor for creators" |
| 狙う案件 | ElevenLabs、Murf、Synthesia、Descript、OpusClip、Castmagic、Gamma |
| 約束 | 実サンプル＋価格＋商用利用条件。free tier から有料への判断材料 |

### O2. 小規模事業者／マーケター（高単価）

| 項目 | 内容 |
|---|---|
| 属性 | 30-55代。DTC・SaaS・エージェンシーの実務者／意思決定者 |
| 悩み | リード獲得、SEO、メール、CRMの効率化とコスト削減 |
| 検索語 | "best SEO tool for small business", "HubSpot vs GetResponse", "Surfer pricing" |
| 狙う案件 | Semrush、HubSpot、GetResponse、Surfer、Frase、AdCreative.ai、n8n、Jotform |
| 約束 | 比較表・ROI試算・cookie/契約条件。CVRは低いが1件あたりが大きい |

### O3. 開発者／no-code ビルダー

| 項目 | 内容 |
|---|---|
| 属性 | 20-40代。自動化・プロトタイプ作成・AIアプリ開発 |
| 悩み | 反復作業の自動化、アイデアの早期検証 |
| 検索語 | "n8n vs Zapier", "AI app builder", "Lovable pricing", "BASE44 review" |

### 除外する海外ペルソナ

- **CapCut を中心に据える層**：program が米国／英国／ドイツ／フランス対象で、日本から安定参加できないため除外
- **Instagram/TikTok のフォロワー5,000人以上が必須の案件（HeyGen等）を前提とする層**：ブログ主体の当siteでは成果条件を満たせないため除外
- **米国居住・SSN 必須の案件を求める層**：W-8BEN でも参加できないものは対象外

## 6. 二軸の優先順位

1. **日本軸を先に立ち上げる**（A8案件で成果が早く、ノウハウも流用できる）
2. 日本軸で記事10本＋GSC流入が出たら、**同じ記事構成を英語化して海外軸を開始**
3. 海外軸は **O1 → O2 → O3** の順に広げる（O1が最も少ない工数で成果条件に近い）
